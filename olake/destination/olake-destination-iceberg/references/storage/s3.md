# Amazon S3 storage

Used by `glue`, `hive`, `jdbc`, `rest`, `nessie` and catalogs that do not vend credentials.

| Field | Value |
| --- | --- |
| `iceberg_s3_path` | `s3://<bucket>/<path>` (Hive also accepts `s3a://`) |
| `aws_region` | the bucket's region |
| `aws_access_key`, `aws_secret_key`, `aws_session_token` | optional; leave out for the default chain |
| `aws_profile` | a profile in a mounted `~/.aws` |
| `s3_endpoint`, `s3_path_style`, `s3_use_ssl` | leave out for AWS |

Credential order when keys are left out: `AWS_*` environment variables on the container, the
profile, then the instance or pod role (EC2 instance profile, EKS IRSA). Pass environment variables
with `docker run -e AWS_ACCESS_KEY_ID -e AWS_SECRET_ACCESS_KEY -e AWS_REGION ...`.

Minimum policy on the warehouse path:

```json
{
  "Effect": "Allow",
  "Action": ["s3:ListBucket", "s3:GetBucketLocation", "s3:GetObject", "s3:PutObject", "s3:DeleteObject"],
  "Resource": ["arn:aws:s3:::<BUCKET>", "arn:aws:s3:::<BUCKET>/*"]
}
```

A KMS-encrypted bucket also needs `kms:Decrypt` and `kms:GenerateDataKey` on the key.
